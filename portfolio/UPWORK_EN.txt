PROJECT TITLE
Data Extraction | PDF to Excel, CSV & JSON

MY ROLE
Python Developer | Data Extraction & Data Cleaning

PROJECT DESCRIPTION
I developed a local Python application to extract tables from digital PDFs and convert Excel, CSV and JSON files. It includes source previews, optional cleaning, multipage table merging, Italian/English number conversion and batch exports. Excel reports document data quality, applied operations and row-level source traceability. Synthetic examples cover sales records, contacts and product prices, with original PDFs and reviewed outputs. Built with Python, pandas, pdfplumber and Streamlit.
